# Implementation Plan: Full Site Redesign

## Overview

Применение существующей дизайн-системы (Section, Card, IconBadge, BrandIcon, хуки анимаций, CSS-токены) ко всем оставшимся страницам NOXISS.WORK. Каждая страница преобразуется как атомарная единица по единому алгоритму: замена токенов → обёртка в Section → обёртка в Card → интеграция анимаций → устранение Anti-AI паттернов → аудит адаптивности. Страницы упорядочены от простых к сложным для ранней валидации подхода.

## Notes

- Каждое преобразование страницы атомарно — сборка должна проходить после каждой завершённой страницы
- Только визуальные изменения: CSS-классы, обёртки Section/Card, хуки анимаций. Никаких изменений бизнес-логики, стейта, API или роутинга
- Property-based тестирование не применимо (чисто UI-работа) — верификация через целостность сборки и визуальную регрессию
- Все хуки анимаций уже интегрируют `useReducedMotion` — дополнительная обработка a11y не нужна
- При добавлении ref от `useScrollAnimation` оборачивать в дополнительный `<div>` чтобы не перезаписывать существующие ref
- Правило чередования вариантов Section: никогда не ставить light рядом с accent (ΔL слишком мал)
- Контрольные точки обеспечивают инкрементную валидацию между группами связанных страниц
- Задачи ссылаются на конкретные требования для трассируемости
